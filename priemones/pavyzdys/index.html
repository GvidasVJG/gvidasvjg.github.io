Vienas mažas pavyzdys – sąlygos, dalybos liekana ir pirmieji žingsniai su versijų kontrole.

Išbandyk „Foo Bar“

Jei skaičius dalijasi iš 3, gausi „Foo“, iš 5 – „Bar“, iš abiejų – „Foo Bar“. Kitu atveju liks pats skaičius.

Foo Bar

Tas pats „Python“ kalba

# Foo Bar simple Programa

# Vartotojas įveda skaičių
# Vietoj skaičių, dalių iš 3, spausdinama "Foo".
# Vietoj skaičių, dalių iš 5, spausdinama "Bar".
# Vietoj skaičių, dalių iš 3 ir 5, spausdinama "Foo Bar".
# Kitu atveju, skaičius spausdinamas nepakitęs.

n = int(input("Įveskite skaičių: "))
if n % 3 == 0 and n % 5 == 0:
    print("Foo Bar")
elif n % 3 == 0:
    print("Foo")
elif n % 5 == 0:
    print("Bar")
else:
    print(n)
Atsisiųsti „Python“ pavyzdį ↓

Pabandyk pats

  1. Rask skaičių, kuriam gausi tik „Foo“.
  2. Paaiškink, kodėl pirmiausia tikrinama dalyba ir iš 3, ir iš 5.
  3. Pakeisk daliklius ir palygink rezultatus.

Versijų kontrolė

Pasidaryk šios saugyklos kopiją, pakeisk pavyzdys/main.py ir išsaugok pakeitimą su aiškiu aprašu. „Git“ leidžia palyginti versijas ir grįžti prie ankstesnio sprendimo.
