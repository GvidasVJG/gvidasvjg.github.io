# Procesoriaus simuliatorius

Mokomasis 8 bitų procesorius su 256 baitais atminties, registrais R0–R2, PC, IR ir požymiais ZF bei SF. Atverk `index.html` arba svetainės `/priemones/Simple-CPU/` puslapį. Lietuviška komandų lentelė, pavyzdžiai ir užduotys pasiekiami mygtuku „Pagalba“.

Komandų kodai ir esamų programų formatas išsaugoti. Skaičiai įvedami šešioliktainiu formatu.
